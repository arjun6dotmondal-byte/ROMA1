ROMA AI — STARTER APP

This is the first visual prototype of your personal assistant.
It is NOT yet connected to an AI model. The chat currently shows a setup
message rather than pretending to generate AI answers. Personal notes are
saved locally in this browser on this device.

NEXT STEP
To install this as an Android home-screen app, these files must be hosted
on an HTTPS website. We can do that using a free hosting service in the
next step. Then open the website in Chrome on your Vivo phone and choose
Add to Home screen / Install app.

SECURITY
Do not put an AI API key in these files. A secure backend is needed before
connecting a real AI model.
